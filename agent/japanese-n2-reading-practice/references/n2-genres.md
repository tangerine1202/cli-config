# N2 読解 register & genre reference

Two ways this file is used:

1. **Article-first (default):** pick the register and rhetorical shape that best matches the
   transcript, and write the full-length immersion article in that style so the reading practice
   transfers to the N2 exam. Most spoken episodes map to 随筆 (reflective essay) or 論説文
   (expository/argumentative). You are not limited to the exam's short lengths here — write a
   full long read.

2. **Mock-test mode (only when the user asks):** reproduce the five real N2 reading genres at
   their true (shorter) lengths, each with its own questions. The length/register/question
   conventions below are what you match in that mode.

---

## 1. 内容理解（短文）— short passage

- **Length:** ~200字, one passage per question.
- **Register:** formal written (だ・である or 丁寧語), a single self-contained paragraph — essay
  excerpt, business memo, or announcement.
- **Questions:** 1, four choices. Stems: 「筆者が最も言いたいことは何か」「〜とあるが、どういうことか」.

## 2. 内容理解（中文）— medium passage

- **Length:** ~500字, expository or narrative-essay style. This is the register closest to a
  thoughtful spoken monologue once fillers and audience address are stripped out — a natural
  default for the article-first mode's *register* (though the article runs longer than 500字).
- **Questions:** 2–3, four choices; at least one targets the overall claim, not just a detail.
  Stems: 「筆者の考えに合うのはどれか」「下線部『〜』とはどういう意味か」.

## 3. 統合理解 — integrated comprehension

- **Length:** two texts, ~250–300字 each, same topic, different standpoints.
- **Construction:** transcript's view = text A; invent a plausible text B (partial agreement,
  different angle, or counterpoint) grounded in a real detail from the source — never a strawman.
- **Questions:** 2, four choices, always requiring both texts: 「AとBに共通するのは」「立場の違いは」.
- **Good fit:** opinion/culture topics where reasonable people disagree.

## 4. 主張理解（長文）— long argumentative passage

- **Length:** ~900字, single passage, editorial/column register (である体 common).
- **Content:** clear thesis, supporting reasoning, an acknowledged counterpoint, a conclusion.
  Expand the transcript's core claim with grounded supporting detail so it reads like a real
  op-ed. (In article-first mode, this is often the closest model for a substantive argumentative
  episode — and you can go longer than 900字.)
- **Questions:** 3, four choices, including one thesis question: 「筆者が最も言いたいことは何か」.

## 5. 情報検索 — information retrieval

- **Length:** ~600–700字 as a realistic scannable document — flyer, schedule, listing, notice —
  with headings, bullets, labels, a table if relevant. Not prose.
- **Construction:** find the practical "what would the notice look like" angle on the topic.
- **Questions:** 2, four choices, conditional/scenario-based: 「〜という条件の人はどうすればよいか」.
- **Good fit:** transcripts with concrete, actionable content (rules, schedules, how-tos).

---

## Choosing register for the article-first mode

- Reflective / personal / life-lesson episode → 随筆 in polished です・ます. (e.g. a travel
  reflection, a "what I learned" episode.)
- Explaining how/why something works, or arguing a position → 論説文 in だ・である.
- If the source genuinely contains two opposing positions and the user wants contrast, consider
  building a 統合理解 mock-test item instead of a single article.

State the chosen genre in the article's metadata block. If the user names a genre, follow it.
